# 月湖夜钓 · Moonlake Fishing

一款月夜星空主题的钓鱼经营小游戏。纯 **HTML5 + Canvas** 单文件实现，零依赖、零构建，打开即玩。

在满月的湖边支起鱼竿，垂钓、刮鳞、下厨、经营渔村，追逐那条传说中的「月神鱼」。

> 🎣 在线试玩：<https://vermouth777.github.io/fish-game/>

---

## ✨ 特色亮点

- **剧情关卡 + 完整垂钓闭环** —— 3 个章节，从「瞄准 → 抛竿 → 咬钩 → 起竿 → 拉扯 QTE → 收竿」一气呵成。
- **新手教学** —— 10 步强制引导，第一次打开也能快速上手。
- **经营链玩法** —— 垂钓 → 刮鳞 → 渔村（市场 / 厨房 / 商店）→ 下一夜，形成完整的养成循环。
- **10 种鱼 + 图鉴收集** —— 从浅滩的小银鱼到深湖的月神鱼，稀有度 1~5 星。
- **多结局** —— 根据三夜总分结算 S / A / B / C 四档结局。
- **画面质感升级** —— Bloom 后处理辉光、银河星云、水面倒影、水下体积光、栈桥渔夫剪影与摇曳灯笼。
- **Web Audio 合成音效 + localStorage 存档** —— 无需任何音频 / 图片外部资源。

## 🎮 玩法介绍

### 1. 垂钓

对准水层、抛出鱼钩，等待鱼咬钩后完成拉扯 QTE 把鱼拉上来。鱼分布在不同的水深，准星会提示当前水层住着什么鱼。

- 徒手点击水面也能直接抓鱼，用来在等待咬钩的间隙续连击。
- 连击越高，分数倍率越高（最高 ×5）。
- 小心**水母**——它会假咬钩，钓上来扣 25 分。

### 2. 刮鳞

钓上来的鱼可以在处理台刮鳞，共 16 段鳞片，按手法分为 5 档品质：

| 品质 | 名称 | 售价倍率 |
| ---- | ---- | -------- |
| S    | 极上 | ×2.00 |
| A    | 上等 | ×1.50 |
| B    | 普通 | ×1.05 |
| C    | 破损 | ×0.60 |
| raw  | 未处理 | ×0.50 |

### 3. 渔村经营

处理好的鱼在渔村可以有三种去向：

- **市场** —— 每日浮动价格，直接卖出。
- **厨房** —— 用鱼做菜，售价更高，但要通过火候 QTE（部分菜谱有最低品质门槛）。
- **商店** —— 用赚到的金币升级装备。

### 4. 图鉴与结局

钓到过的鱼会收录进图鉴。通关三夜后，根据总分结算结局，收集全部鱼种冲击「月光渔王」结局。

## ⌨️ 操作指南

| 操作 | 按键 |
| ---- | ---- |
| 移动准星 | 方向键 / `WASD` |
| 抛竿 / 收竿 / 确认 | `空格` 或 `Enter` |
| 徒手抓鱼 | 鼠标 / 触摸点击水面 |
| 提前收竿（达标后） | `F` |
| 重新开始关卡 | `R` |
| 暂停 / 继续 | `P` 或 `Esc` |
| 静音 | `M` |

> 📱 移动端也支持触摸操作，屏幕左下角有方向键 + 「钓」按钮。

## 🛠️ 技术说明

- **技术栈**：原生 HTML5 + Canvas 2D + JavaScript（ES6），无任何框架或第三方库。
- **单文件结构**：游戏逻辑全部内联在 `fish_game.html` 中，`index.html` 为其副本（用于 GitHub Pages 根入口）。
- **音频**：通过 Web Audio API 实时合成音效，不依赖音频文件。
- **存档**：进度、金币、图鉴、最高分保存在浏览器 `localStorage`。
- **渲染**：Canvas 分层绘制（星空 / 水面 / 水下 / 粒子），配合离屏预渲染精灵与 Bloom 辉光后处理。

## 🚀 本地运行

无需安装任何依赖，任选其一：

1. **直接打开** —— 用浏览器打开 `fish_game.html`（或 `index.html`）即可游玩。
2. **本地服务器**（可选）—— 在项目目录下启动任意静态服务器，例如：

   ```bash
   # Python
   python -m http.server 8000
   # 或 Node.js
   npx serve .
   ```

   然后访问 `http://localhost:8000`。

3. **部署到 GitHub Pages** —— 仓库已启用 Pages，`main` 分支更新后自动发布到 `https://vermouth777.github.io/fish-game/`。
